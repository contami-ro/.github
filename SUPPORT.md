# Support

If you use [contami.ro](https://contami.ro) and need help with the product,
your account, or billing — email **razvan@timis.dev** or use the contact
options on the site. The repositories in this organization are private and for
development only; product questions do not belong in GitHub issues.

## Development

For anything about the code, open an issue in the repository the change
belongs to. If you are unsure which one, ask before opening.
